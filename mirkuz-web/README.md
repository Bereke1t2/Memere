# 🌟 Mirkuz (ምርኩዝ) — Web Landing Page

The high-conversion, mobile-optimized marketing landing page for **Mirkuz** — Ethiopia's premier Grade 12 National University Entrance Examination preparation platform.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
cd mirkuz-web
pnpm install
```

### 2. Run Development Server
```bash
pnpm dev
```
> The landing page will be live at `http://localhost:3001`.

### 3. Build for Production
```bash
pnpm build
pnpm start
```

## 📦 Key Sections & Features
- **Hero**: Ethiopian MoE alignment badge, Google Play Store download, Telegram community join, ratings, and 3D Phone Mockup.
- **Trust Stats**: 50+ courses, 10,000+ past exam questions (2008–2016 E.C.), 100% offline study, instant Telebirr activation.
- **Curriculum Switcher**: Interactive Natural Science vs Social Science tabs with complete subject details.
- **Features Bento Grid**: Low-bandwidth HLS streaming, 100% data-free offline mode, timed mock entrance exams, Mirkuz AI mascot tutor, and weak-area diagnostics.
- **Interactive Live Mock Exam Demo**: Real playable Grade 12 entrance question widget with instant feedback and step-by-step reasoning.
- **Offline Mode Showcase**: Explains how students save 15+ GB of mobile data monthly.
- **Transparent ETB Pricing**: Free starter trial, Single Subject pass (350 ETB), and All-Access Pass (1,450 ETB) with Telebirr & CBE Birr badges.
- **Testimonials**: Real top scorer outcomes and university placements.
- **FAQ Accordion**: Comprehensive answers to data consumption, payments, and curriculum.
- **Footer**: Direct link to the Teacher & Admin portal and Telegram community.
